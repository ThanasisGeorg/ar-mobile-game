# Ερωτηματολόγια

Το κείμενο που βλέπει ο συμμετέχων ορίζεται στο `Assets/Scripts/Research/Questionnaires.cs`.
Η ελληνική απόδοση είναι προσαρμογή των πρωτότυπων αγγλικών ερωτήσεων, οι οποίες παρατίθενται για αναφορά.

## 1. SUS – System Usability Scale (Brooke, 1996)

Κλίμακα: 1 = Διαφωνώ απόλυτα … 5 = Συμφωνώ απόλυτα. Οι ζυγές ερωτήσεις είναι αρνητικά διατυπωμένες.

Βαθμολογία = [Σ(μονές − 1) + Σ(5 − ζυγές)] × 2,5, εύρος 0–100.

| Κωδ. | Ελληνικά | Πρωτότυπο |
|---|---|---|
| SUS01 | Νομίζω ότι θα ήθελα να παίζω αυτό το παιχνίδι συχνά. | I think that I would like to use this system frequently. |
| SUS02 | Βρήκα το παιχνίδι άσκοπα πολύπλοκο. | I found the system unnecessarily complex. |
| SUS03 | Θεώρησα ότι το παιχνίδι ήταν εύκολο στη χρήση. | I thought the system was easy to use. |
| SUS04 | Νομίζω ότι θα χρειαζόμουν βοήθεια από κάποιον έμπειρο για να μπορέσω να το παίξω. | I think that I would need the support of a technical person to be able to use this system. |
| SUS05 | Βρήκα ότι οι διάφορες λειτουργίες του παιχνιδιού ήταν καλά ενσωματωμένες. | I found the various functions in this system were well integrated. |
| SUS06 | Θεώρησα ότι υπήρχε υπερβολική ασυνέπεια στο παιχνίδι. | I thought there was too much inconsistency in this system. |
| SUS07 | Φαντάζομαι ότι οι περισσότεροι άνθρωποι θα μάθαιναν να παίζουν αυτό το παιχνίδι πολύ γρήγορα. | I would imagine that most people would learn to use this system very quickly. |
| SUS08 | Βρήκα το παιχνίδι πολύ δύσχρηστο. | I found the system very cumbersome to use. |
| SUS09 | Ένιωσα πολύ σίγουρος/η παίζοντας το παιχνίδι. | I felt very confident using the system. |
| SUS10 | Χρειάστηκε να μάθω πολλά πράγματα πριν μπορέσω να ξεκινήσω με το παιχνίδι. | I needed to learn a lot of things before I could get going with this system. |

## 2. iGEQ – In-game Game Experience Questionnaire (IJsselsteijn, de Kort & Poels, 2013)

Κλίμακα: 0 = Καθόλου, 1 = Λίγο, 2 = Μέτρια, 3 = Αρκετά, 4 = Πάρα πολύ.

| Κωδ. | Ελληνικά | Πρωτότυπο |
|---|---|---|
| iGEQ01 | Με ενδιέφερε η «ιστορία» του παιχνιδιού. | I was interested in the game's story. |
| iGEQ02 | Ένιωσα επιτυχημένος/η. | I felt successful. |
| iGEQ03 | Βαρέθηκα. | I felt bored. |
| iGEQ04 | Το βρήκα εντυπωσιακό. | I found it impressive. |
| iGEQ05 | Ξέχασα τα πάντα γύρω μου. | I forgot everything around me. |
| iGEQ06 | Ένιωσα απογοήτευση. | I felt frustrated. |
| iGEQ07 | Το βρήκα κουραστικό. | I found it tiresome. |
| iGEQ08 | Ένιωσα εκνευρισμένος/η. | I felt irritable. |
| iGEQ09 | Ένιωσα ικανός/ή. | I felt skilful. |
| iGEQ10 | Απορροφήθηκα πλήρως από το παιχνίδι. | I felt completely absorbed. |
| iGEQ11 | Ένιωσα ικανοποιημένος/η. | I felt content. |
| iGEQ12 | Ένιωσα ότι το παιχνίδι μού έθετε πρόκληση. | I felt challenged. |
| iGEQ13 | Χρειάστηκε να καταβάλω μεγάλη προσπάθεια. | I had to put a lot of effort into it. |
| iGEQ14 | Ένιωσα ωραία. | I felt good. |

**Παράγοντες** (μέσος όρος των δύο ερωτήσεων):

| Παράγοντας | Ερωτήσεις |
|---|---|
| Ικανότητα (Competence) | 2, 9 |
| Αισθητηριακή & φανταστική εμβύθιση (Immersion) | 1, 4 |
| Ροή (Flow) | 5, 10 |
| Ένταση/Ενόχληση (Tension) | 6, 8 |
| Πρόκληση (Challenge) | 12, 13 |
| Αρνητικό συναίσθημα | 3, 7 |
| Θετικό συναίσθημα | 11, 14 |

## 3. Ειδικές ερωτήσεις της μελέτης

Κλίμακα 0–4 (όπως στο iGEQ). Αφορούν πτυχές όπου αναμένεται διαφορά μεταξύ AR και κλασικής έκδοσης.

| Κωδ. | Ελληνικά | English |
|---|---|---|
| C01_fatigue | Ένιωσα σωματική κούραση (π.χ. στα χέρια, στους ώμους ή στον αυχένα). | I felt physical fatigue (arms, shoulders, neck). |
| C02_discomfort | Ένιωσα ζάλη, ναυτία ή οπτική ενόχληση. | I felt dizziness, nausea or visual discomfort. |
| C03_presence | Ένιωσα ότι το πεδίο της μάχης ήταν μέρος του χώρου γύρω μου. | I felt the battlefield was part of the space around me. |
| C04_precision | Ήταν εύκολο να τοποθετήσω τους πύργους ακριβώς εκεί που ήθελα. | It was easy to place the towers exactly where I wanted. |
| C05_overview | Μπορούσα εύκολα να έχω εικόνα όλου του πεδίου της μάχης. | I could easily keep an overview of the whole battlefield. |

## 4. Τελικό ερωτηματολόγιο (μία φορά, μετά και τις δύο εκδόσεις)

Απαντήσεις σύγκρισης: 0 = Κλασική, 1 = AR, 2 = Καμία διαφορά.

| Κωδ. | Ερώτηση | Επιλογές |
|---|---|---|
| F01_preference | Ποια έκδοση προτιμήσατε συνολικά; | Κλασική / AR / Καμία διαφορά |
| F02_fun | Ποια έκδοση ήταν πιο διασκεδαστική; | Κλασική / AR / Καμία διαφορά |
| F03_ease | Ποια έκδοση ήταν πιο εύκολη στον χειρισμό; | Κλασική / AR / Καμία διαφορά |
| F04_immersion | Ποια έκδοση σας έκανε να νιώσετε πιο «μέσα» στο παιχνίδι; | Κλασική / AR / Καμία διαφορά |
| F05_strategy | Σε ποια έκδοση σχεδιάσατε καλύτερα τη στρατηγική σας; | Κλασική / AR / Καμία διαφορά |
| F06_again | Ποια έκδοση θα παίζατε ξανά στον ελεύθερο χρόνο σας; | Κλασική / AR / Καμία διαφορά |
| D01_age | Ηλικιακή ομάδα | 0 = 18-24 / 1 = 25-34 / 2 = 35-44 / 3 = 45+ |
| D02_gender | Φύλο | 0 = Άνδρας / 1 = Γυναίκα / 2 = Άλλο / Δεν απαντώ |
| D03_gaming | Πόσο συχνά παίζετε παιχνίδια στο κινητό; | 0 = Ποτέ / 1 = Μηνιαία / 2 = Εβδομαδιαία / 3 = Καθημερινά |
| D04_ar | Πόση εμπειρία έχετε με εφαρμογές ή παιχνίδια AR; | 0 = Καμία / 1 = Λίγη / 2 = Αρκετή / 3 = Πολλή |
| D05_td | Έχετε παίξει ξανά παιχνίδια Tower Defense; | 0 = Ποτέ / 1 = Λίγες φορές / 2 = Συχνά |
